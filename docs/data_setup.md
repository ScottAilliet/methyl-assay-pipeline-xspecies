# Data Setup Guide

This document describes the data directory structure and how to obtain all
reference data needed to run the cell-specific epigenetic dPCR assay design pipeline.

## Directory Structure

```
data/
├── dmr_regions_v2.2.8_260714.xlsx  # DMR input for pipeline runs
├── sample_groups.csv        # Full Loyfer atlas group definitions
├── sample_manifest.csv      # Sample manifest for beta file downloads
├── hg19/                        # Reference genome (downloaded, .gitignored)
│   ├── hg19.fa.gz               # hg19 genome FASTA (bgzip + faidx indexed)
│   ├── hg19.fa.gz.fai           # samtools faidx index
│   ├── genomicSuperDups.bed.gz  # UCSC segmental duplications track
│   ├── genomicSuperDups.bed.gz.tbi
│   ├── rmsk.bed.gz              # UCSC RepeatMasker track
│   └── rmsk.bed.gz.tbi
├── dbsnp/                       # dbSNP common variants (downloaded, .gitignored)
│   ├── dbsnp_common.vcf.gz      # dbSNP b151 GRCh37, MAF >= 1%
│   └── dbsnp_common.vcf.gz.tbi  # tabix index
└── beta_files/                  # WGBS beta files from GEO (downloaded, .gitignored)
```

## Quick Start

```bash
# Download all reference data (~10 GB total, ~30-60 min)
./download_data.sh

# Run the pipeline
python -m methyl_panel.pipeline \
    --dmr-xlsx data/dmr_regions_v2.2.8_260714.xlsx \
    --genome data/hg19/hg19.fa.gz \
    --dbsnp data/dbsnp/dbsnp_common.vcf.gz \
    --direction hypo \
    --min-tm 55 --opt-tm 58 --max-tm 61 \
    --product-size-min 40 --product-size-max 150
```

## Data File Details

### hg19 genome
Downloaded from UCSC:
```
https://hgdownload.soe.ucsc.edu/goldenPath/hg19/bigZips/hg19.fa.gz
```
Indexed with `samtools faidx`. If the file is gzip (not bgzip), it is
recompressed to bgzip format for faidx compatibility.

### dbSNP common variants
dbSNP build b151 for GRCh37/hg19, common variants (MAF >= 1%):
```
https://ftp.ncbi.nlm.nih.gov/snp/organisms/human_9606_b151_GRCh37p13/VCF/00-common_all.vcf.gz
```
Indexed with `tabix -p vcf`.

### UCSC tracks (segmental duplications + RepeatMasker)
Downloaded from UCSC goldenPath database and converted to BED format:
```
https://hgdownload.soe.ucsc.edu/goldenPath/hg19/database/genomicSuperDups.txt.gz
https://hgdownload.soe.ucsc.edu/goldenPath/hg19/database/rmsk.txt.gz
```

### ePCR genome arrays
Bisulfite-converted hg19 genome in `.npy` format for hash-based ePCR screening.
Generated by `prepare_genomes.py` from the hg19 FASTA:
```bash
python prepare_genomes.py --output-dir data/hg19_bs --genome data/hg19/hg19.fa
```
Produces per-chromosome `.npy` files for 4 bisulfite conversion states
(unmethylated CT/GA, methylated CT_M/GA_M).

### Beta files (WGBS atlas)
207 beta files from GEO accession GSE186458 (Loyfer et al. 2023).
Downloaded by `download_data.sh` using the manifest in
`data/sample_manifest.csv`.
